Los tipos de aprendizaje no se distinguen por el algoritmo, sino por una sola pregunta: **¿de dónde sale la señal que le dice al modelo si lo está haciendo bien?**

@fig(tipos | Los cinco paradigmas, según el origen de la señal de aprendizaje.)

## Aprendizaje supervisado

::: def Aprendizaje supervisado
Cada ejemplo de entrenamiento es un par $(\mathbf{x}, y)$: una entrada y su respuesta correcta, llamada **etiqueta**. El modelo aprende la función que lleva de $\mathbf{x}$ a $y$.
:::

- Si $y$ es un número continuo, la tarea es **regresión**: predecir el precio de una casa, la temperatura de mañana.
- Si $y$ es una categoría, es **clasificación**: spam o no spam, qué dígito aparece en la imagen.

Es el paradigma más directo y el más usado. Su coste es conseguir las etiquetas: alguien tiene que marcar miles de radiografías o de correos. **Módulo 3.**

## Aprendizaje no supervisado

::: def Aprendizaje no supervisado
Solo hay entradas $\mathbf{x}$, sin etiquetas. El objetivo es descubrir estructura: grupos de datos parecidos (**agrupamiento**), las pocas variables que resumen a muchas (**reducción de dimensionalidad**) o qué datos son raros (**detección de anomalías**).
:::

Aquí no hay «respuesta correcta» contra la que medir, y por eso evaluar es más difícil. **Módulo 4.**

## Aprendizaje semi-supervisado

::: def Aprendizaje semi-supervisado
Hay unos **pocos** datos etiquetados y **muchos** sin etiquetar. Se usan las etiquetas para saber qué se busca y los datos sin etiquetar para conocer la forma de los datos.
:::

Es la situación real más frecuente: conseguir un millón de imágenes es barato y etiquetarlas es caro. **Módulo 5.**

## Aprendizaje auto-supervisado

::: def Aprendizaje auto-supervisado
No hay etiquetas humanas, pero se **fabrican** a partir del propio dato: se oculta una parte y se le pide al modelo que la prediga. Ejemplo: tapar una palabra de una frase y adivinarla; predecir la siguiente palabra de un texto.
:::

Técnicamente se entrena igual que el supervisado, pero las etiquetas son gratis, así que se puede entrenar con cantidades inmensas de datos. Así se preentrenan los modelos de lenguaje y los modelos fundacionales de visión. **Módulo 5.**

## Aprendizaje por refuerzo

::: def Aprendizaje por refuerzo
Un **agente** toma decisiones en un entorno y recibe **recompensas**. Nadie le dice cuál era la acción correcta; aprende por ensayo y error qué secuencias de acciones acumulan más recompensa.
:::

Es el paradigma de los juegos (ajedrez, Go), el control de robots y los sistemas que toman decisiones encadenadas. **Módulo 12.**

## ¿Y dónde encajan las PINN?

Una red informada por la física no necesita, en su forma pura, ningún dato etiquetado: la señal de aprendizaje es **cuánto incumple la red una ecuación diferencial conocida**. Puede combinarse con mediciones reales (entonces tiene además una parte supervisada). Es un buen ejemplo de que la clasificación anterior describe el origen de la señal, no el tipo de red.

## Cómo reconocer el tipo de problema

::: ejemplo Cinco situaciones
1. Tienes 50 000 radiografías, cada una con el diagnóstico de un radiólogo. → **Supervisado** (clasificación).
2. Tienes el historial de compras de tus clientes y quieres encontrar perfiles. → **No supervisado** (agrupamiento).
3. Tienes un millón de fotos de piezas de fábrica y solo 200 revisadas por un técnico. → **Semi-supervisado**.
4. Tienes todo el texto de Wikipedia y quieres un modelo que «sepa» el idioma. → **Auto-supervisado**.
5. Quieres que un brazo robótico aprenda a apilar cajas probando. → **Por refuerzo**.
:::

::: ojo Las fronteras no son rígidas
Los sistemas reales mezclan paradigmas. Un asistente conversacional se preentrena de forma auto-supervisada, se ajusta con ejemplos supervisados y se refina con técnicas de refuerzo. Usa estas categorías para pensar, no como cajas estancas.
:::

::: resumen
- **Supervisado:** entradas con etiqueta. Regresión (número) o clasificación (categoría).
- **No supervisado:** solo entradas; se busca estructura.
- **Semi-supervisado:** pocas etiquetas y muchos datos sin etiquetar.
- **Auto-supervisado:** las etiquetas se fabrican ocultando parte del dato.
- **Por refuerzo:** un agente aprende de recompensas.
- Lo que distingue a cada tipo es el origen de la señal de aprendizaje.
:::
