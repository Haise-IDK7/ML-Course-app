## Una CNN desde cero

El programa entrena una CNN sobre los dígitos de 8×8 y la compara con un perceptrón multicapa. Usa esos datos porque vienen con scikit-learn: no hay que descargar nada y entrena en segundos sin GPU.

## Leer el código

**La forma de los datos.** `nn.Conv2d` espera tensores de forma (lote, canales, alto, ancho). Por eso las imágenes se reorganizan con `reshape(-1, 1, 8, 8)`: un canal, 8×8.

**Las capas.**

| Capa | Qué hace | Forma de salida |
|---|---|---|
| `nn.Conv2d(1, 16, 3, padding=1)` | 16 filtros 3×3 sobre 1 canal; el padding conserva el tamaño | 16×8×8 |
| `nn.ReLU()` | no linealidad | 16×8×8 |
| `nn.MaxPool2d(2)` | reduce a la mitad | 16×4×4 |
| `nn.Conv2d(16, 32, 3, padding=1)` | 32 filtros 3×3 sobre 16 canales | 32×4×4 |
| `nn.MaxPool2d(2)` | reduce a la mitad | 32×2×2 |
| `nn.Flatten()` | de tensor a vector | 128 |
| `nn.Linear(128, 10)` | un logit por clase | 10 |

::: ejemplo Resultado
Con la misma receta de entrenamiento: el perceptrón multicapa (7210 parámetros) alcanza un 97.6 % en prueba y la CNN (6090 parámetros) un 98.2 %. La CNN gana con menos parámetros, pero por poco: en imágenes de 8×8 hay poca estructura espacial que aprovechar. En imágenes reales, de cientos de píxeles de lado, la diferencia es enorme.
:::

::: ojo El error más frecuente: la dimensión de la capa lineal
El número de entradas de la primera capa densa depende del tamaño de la imagen y de todas las capas anteriores. Si cambias la resolución, cambia. No lo calcules de memoria: pasa un tensor de prueba por el extractor e imprime su forma, como hace el final del programa.
:::

## Transferencia de aprendizaje

Entrenar una CNN grande desde cero requiere cientos de miles de imágenes etiquetadas y muchas horas de GPU. Casi nunca hace falta.

::: def Transferencia de aprendizaje
Se parte de una red **preentrenada** con un conjunto de datos enorme (ImageNet u otro mayor) y se adapta a la tarea propia. Sus primeras capas ya detectan bordes, texturas y formas, que sirven para casi cualquier imagen.
:::

Hay dos estrategias, según cuántos datos tengas:

| Estrategia | Qué se entrena | Cuándo |
|---|---|---|
| **Extracción de características** | solo una capa final nueva; el resto queda congelado | pocos datos (decenas o cientos por clase) |
| **Ajuste fino** | toda la red, con una tasa de aprendizaje baja | datos suficientes (miles) o dominio distinto del original |

En código, con una ResNet-18 de `torchvision`:

```python
import torch
from torch import nn
from torchvision import models

modelo = models.resnet18(weights=models.ResNet18_Weights.DEFAULT)   # pesos preentrenados en ImageNet

for p in modelo.parameters():          # 1) congelar toda la red
    p.requires_grad = False

modelo.fc = nn.Linear(modelo.fc.in_features, 5)   # 2) sustituir la última capa: 5 clases propias

# 3) entrenar solo la capa nueva
optimizador = torch.optim.AdamW(modelo.fc.parameters(), lr=1e-3)
```

Para el ajuste fino se descongelan todos los parámetros y se usa una tasa mucho menor (por ejemplo $10^{-5}$ a $10^{-4}$), a menudo más baja en las primeras capas que en las últimas.

::: idea Tres detalles que deciden el resultado
1. **Usa el mismo preprocesado que en el preentrenamiento:** misma resolución y misma normalización de colores. Cada conjunto de pesos de `torchvision` trae su transformación: `ResNet18_Weights.DEFAULT.transforms()`.
2. **Aplica aumento de datos** en el entrenamiento, no en la evaluación.
3. **Si tu dominio es muy distinto** (microscopía, satélite, rayos X), la extracción de características sola rinde menos; hace falta ajuste fino o un modelo preentrenado en ese dominio.
:::

## Del ejemplo a MNIST

MNIST (dígitos de 28×28, 60 000 imágenes de entrenamiento) es el paso siguiente natural. Solo hay que cambiar la carga de datos y el tamaño de la capa lineal:

```python
from torchvision import datasets, transforms
datos = datasets.MNIST("datos", train=True, download=True, transform=transforms.ToTensor())
# con dos poolings 2x2: 28 -> 14 -> 7, así que la capa final es nn.Linear(32 * 7 * 7, 10)
```

Una CNN de este tamaño supera el 99 % de exactitud en MNIST tras unas pocas épocas.

## Lista de comprobación al entrenar una CNN

1. ¿Los datos tienen forma (lote, canales, alto, ancho) y están normalizados?
2. ¿La pérdida inicial es cercana a $\ln K$?
3. ¿La red puede sobreajustar un lote de 16 imágenes?
4. ¿Usas `train()` y `eval()` correctamente (por dropout y BatchNorm)?
5. ¿Hay aumento de datos solo en entrenamiento?
6. ¿Comparaste con una línea base simple?

::: resumen
- `Conv2d` espera (lote, canales, alto, ancho); imprime las formas para dimensionar la capa lineal.
- En imágenes pequeñas la ventaja de la CNN es modesta; crece con la resolución.
- En la práctica se usa transferencia de aprendizaje: extracción de características con pocos datos, ajuste fino con más.
- Respeta el preprocesado del modelo preentrenado.
:::
