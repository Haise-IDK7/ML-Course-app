La regresión lineal es el modelo más simple que existe y, a la vez, contiene todas las piezas de una red neuronal: un modelo con parámetros, una función de pérdida y un algoritmo que la minimiza. Si entiendes bien esta lección, el resto del curso es añadir capas.

## El modelo

Queremos predecir un número $y$ (el precio de una casa) a partir de una característica $x$ (su superficie). La **regresión lineal** propone una recta:

$$\hat y = w\,x + b$$

- $w$ es el **peso**: cuánto cambia la predicción por cada unidad de $x$ (la pendiente).
- $b$ es el **sesgo**: la predicción cuando $x = 0$ (la altura de la recta).

Con varias características, $x$ pasa a ser un vector y la suma ponderada es un producto punto: $\hat y = \mathbf{w}\cdot\mathbf{x} + b$.

## La función de pérdida

Hay infinitas rectas. Para elegir hace falta medir con un número cuán mala es cada una.

::: def Función de pérdida y error cuadrático medio
Una **función de pérdida** $L$ asigna a cada elección de parámetros un número que mide cuánto se equivoca el modelo. La habitual en regresión es el **error cuadrático medio** (ECM o MSE):
$$L(w, b) = \frac{1}{n}\sum_{i=1}^{n}\big(\hat y_i - y_i\big)^2$$
Se eleva al cuadrado para que los errores positivos y negativos no se cancelen y para penalizar más los errores grandes.
:::

Entrenar es resolver un problema de optimización: encontrar los $w$ y $b$ que hacen mínima $L$.

## Descenso de gradiente

Para la regresión lineal existe una fórmula exacta, pero para una red neuronal no. El método general es el **descenso de gradiente**:

::: def Descenso de gradiente
1. Empieza con parámetros cualesquiera.
2. Calcula el gradiente de la pérdida: la dirección en la que $L$ crece más deprisa.
3. Da un paso pequeño en la dirección **contraria**:
$$w \leftarrow w - \eta\,\frac{\partial L}{\partial w} \qquad\qquad b \leftarrow b - \eta\,\frac{\partial L}{\partial b}$$
4. Repite hasta que la pérdida deje de bajar.

El número $\eta$ (eta) es la **tasa de aprendizaje**: el tamaño del paso.
:::

Los gradientes salen de la regla de la cadena (lección 1.2):

$$\frac{\partial L}{\partial w} = \frac{2}{n}\sum_i (\hat y_i - y_i)\,x_i \qquad\qquad \frac{\partial L}{\partial b} = \frac{2}{n}\sum_i (\hat y_i - y_i)$$

::: ejemplo Un paso a mano
Datos: $(x, y) = (1, 3)$ y $(2, 5)$. Parámetros iniciales $w = 0$, $b = 0$; tasa $\eta = 0.1$.

1. Predicciones: $\hat y = (0, 0)$. Errores $\hat y - y = (-3, -5)$.
2. Pérdida: $L = \frac{1}{2}(9 + 25) = 17$.
3. Gradientes: $\dfrac{\partial L}{\partial w} = \dfrac{2}{2}\big[(-3)(1) + (-5)(2)\big] = -13$; $\ \dfrac{\partial L}{\partial b} = \dfrac{2}{2}(-3-5) = -8$.
4. Actualización: $w = 0 - 0.1(-13) = 1.3$; $\ b = 0 - 0.1(-8) = 0.8$.
5. Nueva pérdida: predicciones $(2.1, 3.4)$, errores $(-0.9, -1.6)$, $L = \frac{1}{2}(0.81 + 2.56) = 1.685$.

Un solo paso ha bajado la pérdida de 17 a 1.69.
:::

## Experimenta con la tasa de aprendizaje

@lab(regresion-gd)

::: ojo La tasa de aprendizaje es el hiperparámetro más importante
- **Demasiado pequeña:** cada paso avanza poco y el entrenamiento tarda una eternidad.
- **Demasiado grande:** los pasos se pasan de largo del mínimo; la pérdida oscila o crece sin control (diverge).

No hay un valor universal: depende de la curvatura de la pérdida. En la práctica se prueban potencias de 10 ($10^{-1}, 10^{-2}, 10^{-3}\dots$).
:::

## Variantes: por lotes y estocástico

Calcular el gradiente con todos los datos en cada paso es caro cuando hay millones.

::: def Descenso de gradiente estocástico (SGD)
En cada paso se estima el gradiente con un subconjunto pequeño y aleatorio de los datos, llamado **lote** o minilote (típicamente de 16 a 512 ejemplos). Una pasada por todos los datos es una **época**.
:::

El gradiente de un lote es una estimación ruidosa del verdadero, pero es mucho más barato y ese ruido incluso ayuda a escapar de zonas malas. Prácticamente todo el deep learning se entrena así.

::: resumen
- Modelo: $\hat y = \mathbf{w}\cdot\mathbf{x} + b$. Pérdida: error cuadrático medio.
- Descenso de gradiente: mover los parámetros en contra del gradiente, con paso $\eta$.
- $\eta$ pequeña: lento. $\eta$ grande: oscila o diverge.
- SGD: estimar el gradiente con lotes pequeños; una pasada completa es una época.
- Predicción, pérdida, gradientes, actualización: el bucle de todo el curso.
:::
