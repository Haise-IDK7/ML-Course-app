Un modelo de machine learning no ve fotos, frases ni pacientes: ve **números ordenados**. Esta lección presenta las tres formas de ordenarlos y las dos operaciones que más vas a usar.

## Escalares, vectores, matrices y tensores

::: def Las cuatro estructuras
- **Escalar:** un solo número. Ejemplo: la temperatura, $21.5$.
- **Vector:** una lista ordenada de números. Ejemplo: una casa descrita por (superficie, habitaciones, antigüedad) $= (80, 3, 12)$.
- **Matriz:** una tabla de números con filas y columnas. Ejemplo: 100 casas, una por fila, con 3 columnas.
- **Tensor:** lo mismo con cualquier número de ejes. Una imagen en color es un tensor de 3 ejes: alto × ancho × 3 canales (rojo, verde, azul).
:::

Se escribe $\mathbf{x}$ (negrita minúscula) para un vector, $x_i$ para su elemento número $i$, y $W$ (mayúscula) para una matriz, con $W_{ij}$ el elemento de la fila $i$ y la columna $j$. La **forma** (*shape*) de un tensor es la lista de tamaños de sus ejes: una matriz de 100 casas y 3 características tiene forma $(100, 3)$.

::: idea Un dato es un punto
Un vector de $d$ números es un punto en un espacio de $d$ dimensiones. Dos casas parecidas son dos puntos cercanos. Casi todo el machine learning es geometría en ese espacio: trazar fronteras, medir distancias, buscar direcciones.
:::

## El producto punto

Dados dos vectores del mismo tamaño, su **producto punto** multiplica elemento a elemento y suma:

$$\mathbf{w}\cdot\mathbf{x} = \sum_{i=1}^{d} w_i x_i = w_1x_1 + w_2x_2 + \dots + w_dx_d$$

El resultado es un escalar. Tiene dos lecturas:

- **Suma ponderada:** cada $x_i$ cuenta según su peso $w_i$. Así calcula una neurona.
- **Medida de alineación:** $\mathbf{w}\cdot\mathbf{x} = \lVert\mathbf{w}\rVert\,\lVert\mathbf{x}\rVert\cos\theta$, donde $\theta$ es el ángulo entre ambos. Es grande y positivo si apuntan en la misma dirección, 0 si son perpendiculares y negativo si se oponen. Así compara vectores el mecanismo de atención de los Transformers.

::: ejemplo
Con $\mathbf{w} = (0.5, -1, 2)$ y $\mathbf{x} = (4, 3, 1)$:
$\mathbf{w}\cdot\mathbf{x} = 0.5\cdot 4 + (-1)\cdot 3 + 2\cdot 1 = 2 - 3 + 2 = 1$.
:::

La **norma** $\lVert\mathbf{x}\rVert = \sqrt{\sum_i x_i^2}$ es la longitud del vector, y la distancia entre dos puntos es la norma de su diferencia.

## Multiplicar una matriz por un vector

Si $W$ tiene forma $(m, d)$ y $\mathbf{x}$ tiene $d$ elementos, el producto $W\mathbf{x}$ es un vector de $m$ elementos: **el elemento $i$ es el producto punto de la fila $i$ de $W$ con $\mathbf{x}$**.

$$\begin{pmatrix} 1 & 2 \\ 0 & -1 \\ 3 & 1 \end{pmatrix}\begin{pmatrix} 2 \\ 5 \end{pmatrix} = \begin{pmatrix} 1\cdot2 + 2\cdot5 \\ 0\cdot2 - 1\cdot5 \\ 3\cdot2 + 1\cdot5 \end{pmatrix} = \begin{pmatrix} 12 \\ -5 \\ 11 \end{pmatrix}$$

Esto es exactamente una capa de red neuronal: $m$ neuronas, cada una con su fila de pesos, calculando a la vez su suma ponderada sobre la misma entrada. Por eso una capa se escribe $\mathbf{z} = W\mathbf{x} + \mathbf{b}$.

::: ojo La regla de las formas
Para multiplicar $A$ de forma $(m, n)$ por $B$ de forma $(p, q)$ hace falta $n = p$, y el resultado tiene forma $(m, q)$. La mayoría de los errores al programar redes son formas que no encajan. Cuando algo falle, imprime las formas antes que cualquier otra cosa.
:::

La **traspuesta** $W^\top$ intercambia filas y columnas; aparece al propagar gradientes hacia atrás.

## Por qué todo se hace con matrices

Procesar 1000 datos uno a uno con un bucle es lento. Si los apilas como filas de una matriz $X$ de forma $(1000, d)$, la capa entera se calcula con un solo producto, $XW^\top + \mathbf{b}$, que el procesador (o la tarjeta gráfica, GPU) ejecuta en paralelo. A esto se le llama **vectorizar**, y es la razón de que el deep learning sea computacionalmente viable.

::: resumen
- Los datos son vectores (un ejemplo), matrices (muchos ejemplos) o tensores (imágenes, secuencias).
- El producto punto es una suma ponderada y mide alineación.
- $W\mathbf{x} + \mathbf{b}$ calcula de una vez las sumas ponderadas de toda una capa.
- Antes de multiplicar, comprueba las formas.
:::
