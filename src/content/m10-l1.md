Hasta ahora los modelos **discriminaban**: dada una entrada, predecían una etiqueta. Un modelo **generativo** hace lo contrario: aprende cómo son los datos y produce ejemplos nuevos. El punto de partida es una red que aprende a comprimir.

## Autoencoder

@fig(autoencoder | Un autoencoder: comprimir en un código pequeño y reconstruir.)

::: def Autoencoder
Un **autoencoder** tiene dos partes:
- un **codificador** que transforma el dato $\mathbf{x}$ en un código $\mathbf{z}$ de pocas dimensiones;
- un **decodificador** que reconstruye $\hat{\mathbf{x}}$ a partir de $\mathbf{z}$.

Se entrena minimizando el **error de reconstrucción**, $\lVert\mathbf{x} - \hat{\mathbf{x}}\rVert^2$. No necesita etiquetas: el objetivo es la propia entrada.
:::

Como el código es mucho más pequeño que el dato, la red está obligada a quedarse con lo esencial. El espacio de los códigos se llama **espacio latente**.

Si no hay funciones de activación, el autoencoder aprende lo mismo que PCA (lección 4.2). Con ellas, es una reducción de dimensionalidad no lineal.

**Usos:** compresión, eliminación de ruido (se entrena para reconstruir la versión limpia a partir de una con ruido), detección de anomalías por error de reconstrucción (lección 4.3) y preentrenamiento (los *masked autoencoders* de la lección 5.2).

::: ojo Un autoencoder normal no sirve para generar
Podrías pensar: elijo un código $\mathbf{z}$ al azar, lo paso por el decodificador y obtengo un dato nuevo. No funciona. El espacio latente de un autoencoder corriente es irregular, con huecos: la mayoría de los códigos aleatorios caen en zonas que el decodificador nunca vio y producen ruido.
:::

## Autoencoder variacional (VAE)

::: def VAE
Un **autoencoder variacional** (Kingma y Welling, 2014) hace dos cambios:
1. El codificador no devuelve un punto, sino una **distribución**: una media $\boldsymbol{\mu}$ y una desviación $\boldsymbol{\sigma}$ para cada dimensión latente. El código se muestrea de ahí.
2. La pérdida añade un término que empuja esas distribuciones a parecerse a una normal estándar.
:::

$$L = \underbrace{\lVert\mathbf{x} - \hat{\mathbf{x}}\rVert^2}_{\text{reconstruir bien}} + \beta\,\underbrace{D_{KL}\big(\mathcal{N}(\boldsymbol{\mu}, \boldsymbol{\sigma}^2)\,\Vert\,\mathcal{N}(0, I)\big)}_{\text{mantener ordenado el espacio latente}}$$

$D_{KL}$ es la **divergencia de Kullback-Leibler**, una medida de cuánto difieren dos distribuciones. Otra vez una pérdida compuesta con dos objetivos en tensión.

El resultado es un espacio latente continuo y sin huecos: para generar, se muestrea $\mathbf{z}$ de una normal estándar y se decodifica. Moverse suavemente por el espacio latente cambia suavemente el dato generado.

::: idea El truco de reparametrización
Muestrear es una operación aleatoria, y no se puede retropropagar a través del azar. La solución es escribir $\mathbf{z} = \boldsymbol{\mu} + \boldsymbol{\sigma}\odot\boldsymbol{\epsilon}$, con $\boldsymbol{\epsilon}$ ruido normal estándar. Así el azar queda en $\boldsymbol{\epsilon}$, que no depende de los parámetros, y el gradiente puede fluir por $\boldsymbol{\mu}$ y $\boldsymbol{\sigma}$.
:::

Las imágenes de un VAE tienden a salir algo borrosas. Su papel actual es otro: los modelos de difusión que generan imágenes de alta resolución no trabajan con píxeles, sino en el espacio latente de un autoencoder de este tipo, que es mucho más pequeño. A esto se le llama **difusión latente**.

::: ejemplo Los números de una compresión
Una imagen de $512\times512\times3$ tiene 786 432 valores. El autoencoder de un modelo de difusión latente típico la reduce a un tensor de $64\times64\times4 = 16\,384$ valores: 48 veces menos. Todo el proceso generativo ocurre ahí, y solo al final se decodifica a píxeles.
:::

::: resumen
- Un autoencoder comprime a un código latente y reconstruye; se entrena sin etiquetas.
- Sirve para reducir dimensión, quitar ruido y detectar anomalías, pero su espacio latente no es apto para generar.
- Un VAE codifica distribuciones y regulariza el espacio latente hacia una normal: permite muestrear datos nuevos.
- Los modelos de difusión modernos operan en el espacio latente de un autoencoder.
:::
