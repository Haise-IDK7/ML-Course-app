Entrenar un modelo es buscar los parámetros que hacen mínimo un error. Para saber hacia dónde mover cada parámetro hace falta una sola herramienta matemática: la derivada. Esta es la lección de matemáticas más importante del curso.

## La derivada: cuánto cambia la salida si muevo un poco la entrada

::: def Derivada
La derivada de $f$ en $x$ es la pendiente de la curva en ese punto:
$$f'(x) = \frac{df}{dx} = \lim_{h\to 0}\frac{f(x+h)-f(x)}{h}$$
En la práctica: si aumento $x$ en una cantidad pequeña $\varepsilon$, la salida cambia aproximadamente en $f'(x)\,\varepsilon$.
:::

- Si $f'(x) > 0$, subir $x$ hace subir $f$. Para **bajar** $f$ hay que mover $x$ hacia la izquierda.
- Si $f'(x) < 0$, al revés.
- Si $f'(x) = 0$, estás en un punto llano: un mínimo, un máximo o un punto de silla.

De ahí sale el descenso de gradiente, que verás en el módulo 3: moverse siempre **en contra** del signo de la derivada.

Derivadas que usarás constantemente:

| Función | Derivada |
|---|---|
| $x^n$ | $n\,x^{n-1}$ |
| $e^x$ | $e^x$ |
| $\ln x$ | $1/x$ |
| $\sigma(x) = \dfrac{1}{1+e^{-x}}$ (sigmoide) | $\sigma(x)\,(1-\sigma(x))$ |
| $\tanh x$ | $1-\tanh^2 x$ |
| $\max(0, x)$ (ReLU) | $1$ si $x>0$; $0$ si $x<0$ |

## Varias variables: derivadas parciales y gradiente

Un modelo tiene miles o millones de parámetros, así que el error es una función de muchas variables.

::: def Derivada parcial y gradiente
La **derivada parcial** $\dfrac{\partial f}{\partial x_i}$ es la derivada respecto a $x_i$ tratando las demás variables como constantes.
El **gradiente** es el vector que las reúne todas:
$$\nabla f = \left(\frac{\partial f}{\partial x_1}, \frac{\partial f}{\partial x_2}, \dots, \frac{\partial f}{\partial x_d}\right)$$
:::

::: ejemplo
Para $f(x, y) = x^2 + 3xy$: $\ \dfrac{\partial f}{\partial x} = 2x + 3y$ y $\dfrac{\partial f}{\partial y} = 3x$.
En el punto $(1, 2)$ el gradiente es $(8, 3)$: la función crece más deprisa moviéndose sobre todo en $x$.
:::

::: idea El gradiente es una brújula
Imagina la función como un terreno montañoso. El gradiente apunta cuesta arriba por la pendiente más empinada, y su longitud dice cuán empinada es. El vector opuesto, $-\nabla f$, es la dirección de bajada más rápida. Entrenar una red es seguir esa brújula al revés, paso a paso.
:::

## La regla de la cadena

Una red neuronal es una función compuesta: la salida de una capa es la entrada de la siguiente. Para derivar composiciones existe una única regla.

::: def Regla de la cadena
Si $y = f(u)$ y $u = g(x)$, entonces
$$\frac{dy}{dx} = \frac{dy}{du}\cdot\frac{du}{dx}$$
Las derivadas de cada eslabón se **multiplican**.
:::

::: ejemplo Paso a paso
Sea $L = (wx - y)^2$ con $x = 2$, $y = 5$ y $w = 1.5$. Queremos $\partial L/\partial w$.

1. Descompón en eslabones: $u = wx - y$ y $L = u^2$.
2. Valores: $u = 1.5\cdot 2 - 5 = -2$; $L = 4$.
3. Derivadas locales: $\dfrac{dL}{du} = 2u = -4$ y $\dfrac{\partial u}{\partial w} = x = 2$.
4. Multiplica: $\dfrac{\partial L}{\partial w} = -4 \cdot 2 = -8$.

Es negativa: aumentar $w$ reduce el error. Compruébalo: con $w = 1.6$, $L = (3.2-5)^2 = 3.24 < 4$.
:::

Cuando una variable influye en el resultado por varios caminos, se **suman** las contribuciones de cada camino. Multiplicar a lo largo de un camino y sumar entre caminos es todo lo que hace la retropropagación (módulo 6); las librerías lo automatizan con la diferenciación automática.

::: ojo Por qué las redes profundas son delicadas
Con diez eslabones, el gradiente es un producto de diez derivadas. Si cada una vale 0.25, el producto es $0.25^{10}\approx 10^{-6}$: prácticamente nada. Si cada una vale 3, es $59\,049$. A esto se le llama desvanecimiento y explosión del gradiente, y explica muchas decisiones de diseño del módulo 7.
:::

## Derivadas de orden superior

La **segunda derivada** $f''(x)$ es la derivada de la derivada: mide la curvatura. En las PINN aparecen derivadas segundas respecto a la entrada (por ejemplo $\partial^2 u/\partial x^2$), y se obtienen aplicando la diferenciación automática dos veces.

::: resumen
- La derivada dice cuánto y en qué sentido cambia la salida al mover la entrada.
- El gradiente reúne las derivadas parciales y apunta cuesta arriba; para minimizar, se va en sentido contrario.
- Regla de la cadena: multiplicar derivadas locales a lo largo de un camino y sumar entre caminos.
- Un producto de muchas derivadas puede hacerse diminuto o enorme: es el origen del desvanecimiento y la explosión del gradiente.
:::
