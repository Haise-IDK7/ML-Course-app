¿Y si las etiquetas no hicieran falta? El aprendizaje auto-supervisado las **fabrica a partir de los propios datos**. Es la idea que hizo posibles los modelos de lenguaje y los modelos fundacionales de visión.

::: def Aprendizaje auto-supervisado
Se inventa una **tarea pretexto** cuyas respuestas se obtienen del dato sin intervención humana: ocultar una parte y predecirla, o reconocer dos versiones del mismo dato. El modelo no interesa por resolver esa tarea, sino por las **representaciones** que aprende al resolverla.
:::

::: def Representación
Una **representación** (o *embedding*) es el vector de números con el que la red codifica internamente un dato. Una buena representación coloca cerca los datos de significado parecido: las fotos de gatos junto a otras fotos de gatos, aunque nadie le haya dicho qué es un gato.
:::

## Las dos grandes familias

**1. Predecir lo que falta (enmascarado).**

- *Texto:* se tapa una palabra y el modelo la adivina (BERT, 2018), o se predice la siguiente palabra (los modelos GPT). Para acertar, el modelo necesita captar gramática, hechos y contexto.
- *Imágenes:* los *masked autoencoders* (MAE, 2022) ocultan el 75 % de los trozos de una imagen y la red reconstruye el resto.

**2. Comparar vistas (contrastivo y auto-destilación).**

::: def Aprendizaje contrastivo
Se generan dos **vistas** distintas del mismo dato mediante aumento de datos (recortes, cambios de color). La red aprende a dar representaciones parecidas a las dos vistas del mismo dato y distintas a las de datos diferentes.
:::

SimCLR (2020) es el ejemplo de referencia. Variantes como BYOL y **DINO** prescinden de los ejemplos negativos: una red «estudiante» aprende a imitar la salida de una red «maestra», que es un promedio lento del propio estudiante. **CLIP** (2021) aplica la idea contrastiva a pares imagen-texto, alineando ambos en un mismo espacio.

## El flujo de trabajo moderno: preentrenar y adaptar

1. **Preentrenamiento** auto-supervisado con cantidades enormes de datos sin etiquetar. Es muy costoso y se hace una vez.
2. **Adaptación** a la tarea concreta con pocas etiquetas, de una de estas formas:
   - **Sonda lineal:** se congela la red y se entrena solo un clasificador lineal sobre sus representaciones.
   - **Ajuste fino** (*fine-tuning*): se continúa entrenando toda la red, o una pequeña parte, con los datos de la tarea.

::: def Modelo fundacional
Un **modelo fundacional** es un modelo grande, preentrenado de esta manera, que sirve de base para muchas tareas distintas. El término se acuñó en Stanford en 2021.
:::

A reutilizar así lo aprendido se le llama **transferencia de aprendizaje**. Volverá en el módulo 8, aplicada a las CNN.

::: reciente Estado de los modelos de visión auto-supervisados (2025)
**DINOv3** (Meta AI, agosto de 2025) entrenó sin etiquetas un Vision Transformer de unos 7000 millones de parámetros e introdujo una regularización, el *anclaje de Gram*, para evitar que las características locales (por parche) se degraden en entrenamientos largos. Sus representaciones, usadas con la red **congelada**, superan a modelos especializados en tareas densas como la segmentación. Del modelo grande se destilan versiones pequeñas, incluidas variantes con arquitectura convolucional (ConvNeXt) para dispositivos con pocos recursos. En paralelo, la línea **JEPA** propone predecir en el espacio de representaciones en lugar de reconstruir píxeles.
:::

## Cómo se relacionan los tres paradigmas

| | Señal de aprendizaje | Para qué sirve |
|---|---|---|
| No supervisado clásico | ninguna explícita | descubrir estructura (grupos, direcciones) |
| Auto-supervisado | etiquetas fabricadas a partir del dato | aprender representaciones generales |
| Semi-supervisado | pocas etiquetas + estructura de los datos | resolver una tarea concreta con pocas etiquetas |

En la práctica se encadenan: preentrenamiento auto-supervisado, y luego ajuste con las pocas etiquetas disponibles. Esa combinación ha desplazado a muchos métodos semi-supervisados clásicos, como viste al final de la lección anterior.

::: ojo No son gratis
Preentrenar un modelo fundacional requiere una cantidad de cómputo fuera del alcance de casi cualquier laboratorio. Lo habitual es **descargar** uno ya entrenado y adaptarlo. Eso traslada a tu proyecto sus sesgos y sus límites: un modelo preentrenado con fotos de internet puede rendir mal en imágenes médicas o de satélite si no se adapta.
:::

::: resumen
- Auto-supervisado: las etiquetas se generan ocultando o transformando el propio dato.
- Dos familias: predecir lo oculto (BERT, GPT, MAE) y comparar vistas (SimCLR, DINO, CLIP).
- Lo valioso son las representaciones, que se reutilizan con sonda lineal o ajuste fino.
- Preentrenar con datos sin etiquetar y adaptar con pocas etiquetas es hoy el procedimiento estándar.
:::
