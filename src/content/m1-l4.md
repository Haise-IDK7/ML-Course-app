NumPy es la librería de Python para trabajar con arreglos numéricos. Todo el ecosistema de machine learning (scikit-learn, PyTorch) usa sus mismas ideas, así que aprenderlas una vez sirve para todo lo demás.

## Tres ideas que tienes que dominar

::: def Arreglo, forma y eje
Un **arreglo** (`ndarray`) es un tensor: una rejilla de números del mismo tipo. Su **forma** (`.shape`) es la tupla con el tamaño de cada **eje**. En una matriz de datos, el eje 0 recorre los ejemplos (filas) y el eje 1 las características (columnas).
:::

**1. Vectorizar.** En lugar de recorrer los elementos con un bucle `for`, se opera con el arreglo entero: `np.exp(-z)` aplica la exponencial a todos los elementos a la vez, en código compilado. Es entre 10 y 100 veces más rápido y se parece más a la fórmula matemática.

**2. El operador `@`.** Es el producto de matrices (y el producto punto entre vectores). No lo confundas con `*`, que multiplica elemento a elemento.

**3. Broadcasting.** Cuando dos arreglos tienen formas distintas pero compatibles, NumPy «estira» el pequeño para que encaje. Sumar un vector de sesgos de forma `(2,)` a una matriz de forma `(4, 2)` lo suma a cada una de las 4 filas.

::: ojo La trampa del broadcasting
El broadcasting no avisa cuando haces algo que no querías. Restar un arreglo de forma `(n,)` a otro de forma `(n, 1)` no da error: produce una matriz `(n, n)`. Ante un resultado raro, imprime las formas.
:::

## Reproducibilidad

Los algoritmos de ML usan números aleatorios (para inicializar pesos, barajar datos, dividir conjuntos). Si fijas la **semilla** (`np.random.default_rng(seed=42)`) obtienes siempre la misma secuencia y por tanto el mismo resultado. Sin eso, no puedes saber si una mejora se debe a tu cambio o al azar.

::: idea Cómo ejecutar el código del curso en tu PC
Instala Python 3.11 o posterior y, en una terminal dentro de la carpeta `python/` del repositorio: `pip install -r requirements.txt`. Después, `python 01_numpy_basico.py`. Los programas con PyTorch (módulos 7, 8 y 11) solo funcionan así; los demás también se ejecutan dentro de la app.
:::

::: resumen
- Un arreglo tiene forma y ejes; `axis=0` opera a lo largo de las filas (por columna) y `axis=1` a lo largo de las columnas (por fila).
- Vectoriza: opera con arreglos completos en vez de con bucles.
- `@` es el producto de matrices; `*` es elemento a elemento.
- El broadcasting estira formas compatibles; revisa las formas cuando algo no cuadre.
- Fija la semilla para que tus experimentos sean reproducibles.
:::
